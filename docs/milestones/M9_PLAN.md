# M9 구현 계획 (v1) — UX/UI 개선 · "Bitpunk Phosphor"

상태: **제안 — 승인 대기** · 디자인 레퍼런스: 사용자 제공 녹색 CRT 터미널 화면(시스템 로그·재고 표·DOS 디렉터리) + 영화 매트릭스 분위기 ·
목업: Design 캔버스 "Bitpunk Phosphor UI" (디자인 언어 1장 + 화면 9장)

## 0. 원칙 — 멋이 기능을 이기지 않는다

| 원칙 | 내용 |
|---|---|
| **밝기가 곧 중요도** | 녹색 인광 한 가지 위에서 밝기 4단계로 위계를 만든다. 금액·주소·단어처럼 확인해야 할 데이터가 가장 밝다. 호박색·적색은 주의·위험에만 |
| **보이지 않던 검사를 보여 준다** | 터미널 로그 형식(`[ OK ]` `[WARN]` `[FAIL]`)으로 기기가 실제로 확인한 것을 보여 준다: 부팅 자가 점검(통신 칩·USB·펌웨어), 검토 검증(소유·거스름·SIGHASH·수수료), 엔트로피 검사. 장식이 아니라 정보 |
| **정보가 있는 곳에는 비를 내리지 않는다** | 매트릭스 비는 부팅·화면 보호·긴 계산 중에만. 메뉴·검토·단어 화면에는 쓰지 않는다 |
| **QR은 효과 밖** | QR은 밝은 판(#DFFFE6) 위 검은 모듈, 조용한 여백 4칸, 주사선·글로 없음. 판독이 먼저 |
| **색만으로 구분하지 않는다** | 모든 상태에 기호 태그가 함께 있다. 대비는 본문 7:1 이상, 보조 4.5:1 이상 |
| **움직임은 최소** | 깜빡임은 커서 1 Hz뿐, 번쩍임·화면 떨림 없음. 효과는 설정에서 약하게·끔 |
| **한 키, 같은 자리** | 숫자 = 메뉴 번호, 키 막대는 늘 맨 아래 같은 자리, 같은 키는 어디서나 같은 뜻 |
| **주소 중독 공격을 돕지 않는다** | 주소는 4자씩 묶어 모두 같은 밝기로(묶음마다 살짝 번갈아). 앞뒤 몇 글자만 강조하지 않는다 |

## 1. 목표

**완료 기준**
- 모든 화면이 같은 격자·팔레트·조작 규칙을 따른다 (화면 순회 시험이 격자·대비를 검사)
- 효과를 "전체"로 켠 상태에서도 모든 QR 화면을 우리 디코더(bp-qr)가 판독한다 (시험)
- 핵심 과제(12단어 시드 만들기, xpub 내보내기, PSBT 서명 QR·SD, 멀티시그 등록)의 키 입력 수·화면 수가 지금보다 늘지 않는다 (시험이 세서 전후 비교표를 남김; 위험 동작의 단어 입력만 예외로 명시)
- 영·한 전 화면 넘침 없음 (지금 배치 검사 유지)
- 시뮬레이터가 기기와 같은 그림을 그린다 (효과도 `bp-ui`에서 그림)

## 2. 시각 언어

**팔레트** (바탕 #030B05 대비)

| 이름 | 값 | 대비 | 쓰임 |
|---|---|---|---|
| BRIGHT | #D2FFDC | 18.1:1 | 금액·주소·단어·지문 — 확인할 데이터 |
| TEXT | #4DFF7C | 15.1:1 | 본문 |
| SIGNAL | #00FF41 | 14.6:1 | 선택 막대(반전)·커서·진행 |
| DIM | #2BB457 | 7.4:1 | 라벨·보조 설명 |
| FAINT | #13532A | 2.2:1 | 구분선·격자·빈 칸 (글자에는 쓰지 않음) |
| AMBER | #FFB000 | 10.9:1 | 주의, 메인넷 표시, TEST ONLY |
| RED | #FF5555 | 6.3:1 | 위험·실패 |

**격자:** 800×480 = **64×20 칸**(칸 12×24 px, 좌우 여백 16 px). 칸 크기는 지금 본문 글꼴(JetBrains Mono 20 px, 폭 12 px)과 같다. 한글은 2칸.
행 0 상태줄, 1 구분선, 2–17 내용(16줄), 18 구분선, 19 키 막대.
**글자 크기 2단:** 본문 20/24, 이중 크기 40/48(VT100 이중 높이 줄처럼) — 금액·제목·지문에만.

**효과 3단계** (설정 > 화면 효과)

| 단계 | 내용 |
|---|---|
| 전체 | 주사선 25%, 글자 글로, 화면 전환 잔광(2프레임), 부팅·대기 비 |
| **약하게 (기본)** | 주사선 12%, 제목·이중 크기 글자만 글로, 비는 부팅·대기에만 |
| 끔 | 평면 녹색 터미널, 움직임 없음 |

**매트릭스 비:** 글자는 bech32 글자집합(`qpzry9x8gf2tvdw0s3jn54khce6mua7l`) — 비트코인 주소의 글자로 내리는 비. 머리 글자가 가장 밝고 꼬리는 흐려진다.
비의 무작위성은 화면용 의사난수이며 시드 재료와 완전히 분리한다(시드는 지금처럼 주사위·동전만).

## 3. 정보 구조 (안)

지금 주 메뉴(스캔·시드·도구·설정·SD·전원)는 기능이 추가된 순서다. 하는 일 기준으로 다시 묶는다.

| 새 메뉴 | 담는 것 |
|---|---|
| [1] 서명하기 | PSBT(QR·SD 목록), 메시지 서명 |
| [2] 받기·확인 | 주소 보기, 주소 검증, 메시지 서명 검증 |
| [3] 시드·키 | 만들기(주사위·동전·D20), 불러오기, 개인키 가져오기, xpub 내보내기, SeedQR, BIP-85, 패스프레이즈 |
| [4] 지갑 | 멀티시그 등록·목록·주소·내보내기, 지갑 파일 |
| [5] SD 카드 | 파일 관리자, 포맷 |
| [6] 설정 | 네트워크, 언어, 수수료 기준, 메시지 서명, 금액 단위, 화면 효과, 화면 보호, 설정 QR, 정보(버전·예정 기능) |
| [0] 전원 | 끄기 |

- **QR 스캔은 어디서나 Fn+Q** (지금처럼). 스캔한 내용으로 할 일을 자동으로 고른다.
- 아직 없는 기능("M10 예정" 줄)은 메뉴에서 빼고 설정 > 정보 > 예정 기능 한 곳에 모은다.
- 주 메뉴 아래에 **세션 로그**: 켠 뒤 경과 시간과 한 일(시드 불러옴, xpub 내보냄, PSBT 서명…). 금액·주소는 적지 않고, RAM에만 있다가 전원을 끄면 지워진다. (기기에 시계가 없으므로 경과 시간을 쓴다)

## 4. 조작 규칙

| 키 | 뜻 (모든 화면 공통) |
|---|---|
| 숫자 | 메뉴 번호 바로 가기 (입력 화면에서는 입력) |
| Enter | 주 동작 (키 막대에서 SIGNAL 색으로 표시) |
| Esc | 뒤로 / 취소 — 비밀 화면에서는 화면을 지우고 나감 |
| ↑↓ / ←→ | 이동 / 값 바꾸기 |
| S | SD에 저장 (카드가 있을 때만 키 막대에 보임) |
| ? | 이 화면 도움말 (입력 화면에서는 Sym 조합) |
| Fn+Q | QR 스캔 |
| Del | 지우기·되돌리기 |

- 키 막대는 그 화면에서 실제로 되는 키만 보여 준다.
- 되돌릴 수 없는 동작(카드 포맷, 시드 지우기)은 **단어 입력 확인**(`FORMAT`, `WIPE`). 그 밖의 확인은 한 번.

## 5. 공통 화면 패턴

- **상태줄 = 경로 + 보안 상태:** 왼쪽 `BITPUNK:~/서명/PSBT>`(어디에 있는지), 오른쪽 `● 에어갭`(부팅 점검 결과), `SD`, 네트워크(메인넷은 호박색), `TEST`.
- **로그 목록:** `[ OK ]` `[ i  ]` `[WARN]` `[FAIL]` `[ -- ]`(아직 안 함) 태그 + 한 줄 설명.
- **표:** 고정 칸 열(이름·크기·종류), 맨 아래 합계 줄, `PAGE 1 of 3`.
- **경고 3단계:** 정보(녹색), 주의(호박색), 위험(적색 이중선 상자 + `[!!!]`).
- **오류 코드:** 모든 거부·실패에 `E-SD-04` 같은 짧은 코드 + 무엇이 문제인지 + 다음에 할 일. M14 사용 가이드의 문제 해결 장이 코드로 찾아보게 한다.
- **화면 보호:** 입력이 1분(설정 가능) 없으면 비가 내리며 비밀 화면(단어·SeedQR·BIP-85 결과·개인키)을 가린다. 아무 키나 누르면 돌아오되, 비밀 화면은 다시 열어야 보인다.
- **계산 중:** 시드 계산·서명처럼 시간이 걸리는 동안 진행 표시 + 비 띠. 결과(지문 등)가 나오면 그 자리에 고정.
- **첫 실행 안내:** 언어 → 네트워크 → 원칙 3줄(에어갭·주사위·TEST ONLY) → 시드 만들기/불러오기.

## 6. 화면별 개선

| 화면 | 바뀌는 것 |
|---|---|
| 부팅 | 자가 점검 로그: CPU·RAM, **MDIO 0–31 응답 없음**, 무선 없음, USB 데이터 꺼짐, 펌웨어(개발 빌드는 `[WARN]`), SD, 시드. 0.6초, 아무 키나 넘어감 |
| PSBT 검토 | 맨 위 이중 크기 금액 + 수수료(sat·sat/vB·%), 출력마다 두 줄(구분·금액 / 주소 4자 묶음), 아래 **검증 로그**. 멀티시그는 머리말에 지갑·M-of-N·서명 현황 |
| 시드 단어 | 3열 표, 번호 + **앞 4글자 밝게**(입력할 때 4글자로 완성되는 것과 같은 규칙), 가림까지 남은 시간 |
| 엔트로피 | 굴림 판(12단어 50칸·24단어 100칸)이 채워짐, 비트 진행 막대, 통계 검사(분포·연속·자기상관)는 최소 횟수 뒤 로그로 |
| SD 파일 | DOS 디렉터리 목록(볼륨·남은 공간·`<PSBT>` `<지갑>` `<DIR>`·합계 줄), 종류는 내용으로 판별했다고 표시 |
| QR | 왼쪽 밝은 판 QR, 오른쪽 형식·프레임 진행·서명 검증 로그·저장 안내 |
| 위험 확인 | 적색 이중선 상자, 지워질 것의 개수·크기, 단어 입력 |
| 주소·지갑·메시지·설정 | 같은 패턴 적용(표·로그·4자 묶음), 금액 단위 BTC/sats 설정 |

## 7. 실기기 고려 (STM32N6570-DK)

- 주사선·비네트는 **LTDC 두 번째 층**의 정지 이미지로 올리면 프레임마다 드는 계산이 없다. QR이 보일 때만 그 자리를 투명하게 다시 그린다. 시뮬레이터는 같은 결과를 `bp-ui`에서 소프트웨어로 그린다.
- 글로는 글꼴 묶음에 흐린 층을 미리 구워 둔다(이중 크기 글꼴 우선) → 메모리 비용만, 계산 비용 없음.
- 비는 열 단위 부분 갱신. 실제 프레임 시간은 H3에서 측정해 효과 기본값을 다시 확인한다.

## 8. 시뮬레이터 페이지

CRT 모니터 외형의 화면 테두리, 옆 패널(카메라·microSD·부팅 점검)을 같은 터미널 스타일로, 휴대폰 폭에서도 깨지지 않게. "This build" 안내는 시스템 로그 모양으로.

## 9. 범위 밖

- 터치 입력 (보드에 터치 화면이 있으나 키보드 중심 원칙 유지; 필요하면 M12 실기기 UX 점검에서 검토)
- 사용 가이드 본문 (M14). M9는 화면 도움말과 오류 코드까지.
- 실기기 가독성·CardKB 촉감 점검 (M12)

## 11. 커밋 단위

1. **M9-1 디자인 토큰·격자:** 팔레트·밝기 단계, 64×20 칸 배치 API, 이중 크기 글꼴, 구분선·상자, 팔레트 대비 시험
2. **M9-2 효과·비:** 주사선·글로·잔광·커서, 효과 3단계 설정, QR 제외, 매트릭스 비 엔진(bech32, 화면용 의사난수), 렌더 비용 계측
3. **M9-3 공통 틀:** 상태줄(경로·보안 상태), 키 막대, 번호 메뉴·반전 선택, 표·페이지, 로그 목록, 경고 3단계, 단어 입력 확인, 오류 코드 체계
4. **M9-4 정보 구조:** 주 메뉴 재편, 예정 기능 정리, 첫 실행 안내, 세션 로그
5. **M9-5 부팅·화면 보호·계산 중:** 자가 점검 로그 화면, 1분 화면 보호(비밀 가림), 진행 표시
6. **M9-6 검토 화면:** 금액·수수료 머리말, 출력 블록·주소 묶음, 검증 로그(단일·멀티시그), 금액 단위 설정
7. **M9-7 시드·키 화면:** 단어 표, 엔트로피 굴림 판·검사 로그, SeedQR·BIP-85·개인키·패스프레이즈 화면
8. **M9-8 나머지 화면:** 주소·지갑·메시지·SD(디렉터리 목록)·설정
9. **M9-9 도움말·문구·측정:** 화면별 도움말, 영·한 문구 다듬기, 과제별 키 입력·화면 수 전후 비교표
10. **M9-10 시뮬레이터·문서·배포:** 시뮬레이터 페이지 재디자인, 전 화면 영·한 순회, 결과 문서, 배포

## 12. 시험

- **대비:** 팔레트의 모든 글자·바탕 조합이 기준(본문 7:1, 보조 4.5:1)을 넘는지
- **QR:** 효과 "전체"로 모든 QR 화면을 렌더 → bp-qr 디코더가 원래 내용을 읽는지
- **격자:** 글자가 칸에 맞는지, 키 막대·상태줄 자리가 화면마다 같은지 (배치 검사 확장)
- **과제 효율:** 핵심 과제를 키 순서로 재생해 키 입력·화면 수를 세고 M8 기준과 비교
- **기존 시험 전부 유지** (화면 문구가 바뀌는 시험은 새 문구로 고침, 동작은 그대로)
