# M1 구현 계획 — 시드 생성 · 입력

상태: **승인 대기**

## 1. 목표

기기에서 BIP-39 시드를 **만들고, 입력하고, 백업을 확인**할 수 있게 한다.
결과는 공식 테스트 벡터와 SeedSigner·Krux·Coldcard의 계산 방식으로 검증한다.

## 2. 범위

| 포함 | 제외 (다른 마일스톤) |
|---|---|
| SHA-256, SHA-512, HMAC-SHA512, PBKDF2-HMAC-SHA512 | 지문(XFP)·xpub·주소 → M2 (secp256k1 필요) |
| BIP-39 영문: 엔트로피 ↔ 니모닉, 체크섬, 시드 계산 | 패스프레이즈 입력 화면 → M2 |
| TRNG 12/24단어 생성 | 카메라 이미지 엔트로피 → M4 |
| 주사위 D6 생성 (분포 검사 포함) | D20 → M6 |
| QWERTY 단어 입력 + 자동완성, 단어 번호 입력 | SeedQR → M3(출력)/M4(입력) |
| 마지막 단어 계산기 | 기기 내 저장 → M9 (M1은 무상태: 전원 끄면 소멸) |
| 단어 표시, 백업 확인 퀴즈, 세션 시드 목록 | 한국어 → M6 (문자열 표 구조는 M1에서 만듦) |

## 3. 구현 내용

### 3.1 `bp-crypto`
- `sha256`, `sha512`: 스트리밍 API(`update`/`finalize`) + 한 번에 계산하는 함수. 비밀 데이터를 처리한 내부 상태는 drop 시 지움.
- `hmac_sha512`, `pbkdf2_hmac_sha512`.
- 모두 `no_std`, 할당 없음, `unsafe` 없음(기존 `wipe` 제외).

### 3.2 `bp-bitcoin::bip39`
- 단어장: bitcoin/bips 공식 `english.txt`를 그대로 포함하고, 파일 SHA-256을 테스트로 고정.
- `Mnemonic` 타입: 12/15/18/21/24단어, 단어 인덱스(u16)로 보관, drop 시 지움, `Debug`에 단어 노출 안 함.
- 엔트로피 → 니모닉, 니모닉 → 엔트로피(체크섬 검증), `to_seed(passphrase)`.
- 접두어 검색: 입력한 글자로 시작하는 단어 목록. BIP-39 단어는 앞 4글자로 유일하게 정해지므로 4글자에서 자동 확정.
- 마지막 단어 후보: 11/23단어 + 남은 비트(7/3비트) → 체크섬을 채운 마지막 단어.

### 3.3 엔트로피 소스
- **TRNG**: HAL `Rng` trait. 시뮬레이터는 JS의 `crypto.getRandomValues`를 WASM에 연결.
  기기(H 트랙)에서는 TRNG 주변장치 + 여러 소스 혼합.
- **주사위 D6**: SeedSigner·Krux·Coldcard와 같은 방식. 굴린 숫자를 문자열로 이어 SHA-256으로 해시.
  - 12단어: 최소 50회, 해시 앞 16바이트 사용 / 24단어: 최소 99회, 32바이트 사용
  - 최소 횟수를 넘겨 더 굴려도 됨(Krux 방식). 정확히 50/99회면 SeedSigner와 결과가 같음.
  - 분포 검사: 눈별 빈도 막대 + 카이제곱 검정으로 치우침 경고(Coldcard), 연속 패턴 경고(Krux).
  - 굴림 문자열의 SHA-256을 화면에 보여 줘서 외부 도구로 검증 가능하게 함.
- 주사위 생성은 **주사위만으로** 엔트로피를 만든다(TRNG와 섞지 않음). 그래야 외부에서 재현·검증할 수 있음.

### 3.4 `bp-ui` 위젯 추가
- `text_input`: 커서, 글자 입력, Backspace.
- `word_entry`: 현재 단어 입력칸 + 후보 목록 + 지금까지 입력한 단어 격자.
- `word_grid`: 12/24단어를 번호와 함께 표시(24단어는 4열 × 6행).
- `keypad_entry`: 주사위·숫자 입력용(진행 표시 "17 / 50", 빈도 막대).
- `dialog`: 경고·확인 화면(아이콘 + 제목 + 본문 + 버튼).
- 시뮬레이터 빌드에서 상태바에 빨간 **TEST ONLY** 배지를 상시 표시.

### 3.5 `bp-app`
- 문자열 표(`text.rs`): 모든 화면 문구를 한곳에 모음. M1은 영어만 넣고, M6에 한국어를 추가.
- 세션 시드 목록: 최대 3개. 지문이 생기는 M2 전까지는 `"crew…unique (12)"`처럼 첫/마지막 단어로 표시.
- 메뉴의 단계 표시를 P1/P2/P3에서 새 마일스톤 번호(M1~M12)로 변경.

## 4. 화면 흐름

```
Seeds
├─ Create new seed
│   ├─ 12 / 24 words (TRNG) ─► 경고 ─► 단어 표시(페이지) ─► 백업 확인? ─► 퀴즈 ─► 시드 불러옴
│   └─ Dice rolls ─► 12/24 선택 ─► 주사위 입력(1~6 키) ─► 분포·SHA-256 확인 ─► 단어 표시 ─► …
├─ Load seed
│   ├─ Type words ─► 12/24 선택 ─► 단어 입력(자동완성) ─► 체크섬 확인 ─► 시드 불러옴
│   └─ Word numbers ─► 12/24 선택 ─► 1~2048 번호 입력 ─► 체크섬 확인 ─► 시드 불러옴
└─ [불러온 시드] ─► Show words · Verify backup · Discard
Tools
└─ Final word calculator ─► 11/23단어 입력 ─► 남은 비트: 동전 던지기(0/1) | 단어 선택 | 0으로 채움 ─► 마지막 단어 ─► 불러오기?
```

### 단어 입력 키 조작
| 키 | 동작 |
|---|---|
| 글자 | 현재 단어 입력, 후보 목록 즉시 갱신 |
| ▲ ▼ | 후보 선택 |
| Enter / Space / Tab | 선택한 후보로 단어 확정 |
| Backspace | 글자 삭제, 빈 칸이면 이전 단어로 돌아가 수정 |
| Esc | 취소(확인 대화상자) |

- 앞 4글자가 맞으면 자동 확정, 일치하는 단어가 없으면 입력을 받지 않음.
- 마지막 단어까지 입력하면 체크섬을 확인하고, 틀리면 SeedSigner처럼 "체크섬 오류" 화면에서 어떤 단어를 고칠지 고르게 함.

### 백업 확인 퀴즈
- 기본: 12단어는 무작위 위치 4개, 24단어는 6개를 타이핑(자동완성 사용). 설정에서 "전체 단어 확인"으로 변경 가능.
- 틀리면 해당 단어를 다시 보여 주고 재시도.

## 5. 테스트 & 검증

| 대상 | 방법 |
|---|---|
| SHA-256/512 | NIST 예제 벡터 + 테스트 전용 `sha2` 크레이트와 무작위 입력 수천 개 대조 |
| HMAC-SHA512 | RFC 4231 벡터 |
| PBKDF2-HMAC-SHA512 | 공개 벡터 + 테스트 전용 `pbkdf2` 크레이트 대조 |
| 단어장 | 공식 `english.txt`의 SHA-256 고정, 2048개·정렬·앞 4글자 유일성 확인 |
| BIP-39 | Trezor 공식 벡터(엔트로피·니모닉·시드, 패스프레이즈 `TREZOR`) + 테스트 전용 `bip39` 크레이트 대조 |
| 주사위 | **SeedSigner 공식 테스트 벡터**(99회 굴림 → 24단어 2건) + Krux 방식(최소 횟수 초과) |
| 마지막 단어 | SeedSigner의 iancoleman 기반 벡터 |
| 비밀값 | `Debug` 출력에 단어·엔트로피가 나오지 않는지, drop 후 0으로 지워지는지 |
| UI | 화면 흐름 상태 머신 테스트 + 주요 화면 스냅샷(PNG) |
| no_std | Cortex-M 빌드 |

테스트 전용 크레이트(`sha2`, `hmac`, `pbkdf2`, `bip39`)는 `dev-dependencies`에만 들어가고 제품 코드에는 포함되지 않습니다.

## 6. 커밋 단위

1. `bp-crypto`: SHA-256/512, HMAC, PBKDF2 + 테스트
2. `bp-bitcoin`: BIP-39 + 테스트 벡터
3. 엔트로피: TRNG HAL 연결(시뮬레이터) + 주사위 + 분포 검사
4. `bp-ui`: 입력 위젯, TEST ONLY 배지
5. `bp-app`: 문자열 표, 화면 흐름(생성·입력·백업·마지막 단어)
6. 시뮬레이터 배포 + 확인 체크리스트
