# STM32N6570-DK — 개발 보드 준비 (H1, M8 결정 9)

M8 결정 9·9-1·9-2(권장안 승인)에 따른 개발 보드 준비 문서. 비교와 근거는 [M8_SURVEY.md §7](../M8_SURVEY.md).

## 1. 사는 것

| 부품 | 수량 | 메모 |
|---|---|---|
| STM32N6570-DK | **2대** | 한 대로 먼저 제거 작업을 해 본다 (되돌릴 수 없음) |
| M5Stack CardKB v1.1 | 1 | I2C 주소 `0x5F`, Grove(HY2.0-4P) 단자 |
| Grove → 2.54 mm 암 점퍼 케이블 | 1 | CardKB를 아두이노 헤더에 연결 |
| I2C 레벨 변환기 (예: PCA9306) | 1 | CardKB 풀업이 5 V면 필요 (§4) |
| microSD 카드 (≤ 32 GB 권장) | 1~2 | 기기에서 FAT32로 포맷 |

## 2. 떼어 내는 것 (결정 9-1)

| 대상 | 방법 | 이유 |
|---|---|---|
| **이더넷 PHY** (RTL8211F, QFN) | 핫에어 + 플럭스 | 통신 칩 자체를 없앤다 |
| **RJ45 단자** (CN16, 스루홀) | 흡입기·솔더윅 | 밖으로 나가는 물리 경로 |
| PHY 크리스털·마그네틱 | 회로도(UM3300)로 위치 확인 후 | 남겨 둘 이유가 없음 |
| USB OTG Type-C · USB Type-A 단자 | 최종 조립 때 (선택) | 펌웨어는 처음부터 USB 컨트롤러 클록을 켜지 않는다 |

- 작업 전·후 사진을 남기고, 멀티미터로 RGMII 선이 아무 데도 이어지지 않음을 확인한다.
- 개발 중에는 ST-LINK USB(디버그·전원)만 쓴다. 최종 기기는 5 V 핀으로 전원을 넣는다.
- MCU 안의 이더넷 MAC·USB 컨트롤러는 남지만, 밖으로 나가는 물리 계층(PHY·단자)이 없으면 신호 경로가 없다. 펌웨어는 해당 클록을 켜지 않고 핀을 아날로그 입력으로 둔다.

## 3. 부팅 자가 시험 (결정 9-2)

- 부팅할 때마다 MDC·MDIO 핀을 **GPIO로** 움직여(비트뱅) MDIO 주소 0~31의 PHY ID 레지스터(2, 3)를 읽는다. 이더넷 주변장치는 켜지 않는다. 구현: `bp_hal::mdio::scan_phys` (IEEE 802.3 clause 22, 모의 버스 시험 포함).
- 응답이 있으면 `App::set_comm_check(CommCheck::Detected(..))` → 불러온 시드를 모두 지우고 **"통신 칩 감지"** 화면에서 멈춘다. 시드 불러오기·서명 불가, 다시 전원을 켜도 같다.
- 응답이 없으면(풀업으로 모두 1) `CommCheck::Clean`. MDIO 핀이 없는 보드나 시뮬레이터는 `NotRun`.
- 시뮬레이터: 페이지의 "Boot check: simulate an Ethernet chip" 버튼으로 재현.

## 4. CardKB 연결

| CardKB (Grove) | 보드 (아두이노 헤더) |
|---|---|
| GND (검정) | GND |
| 5V (빨강) | 5V |
| SDA (노랑) | D14 (I2C1 SDA) |
| SCL (흰색) | D15 (I2C1 SCL) |

- CardKB는 ATmega8A, 5 V 전원. I2C 신호 전압은 공식 자료에 없으므로 **CardKB 회로도로 풀업 전압을 확인**한다. 5 V 풀업이면 PCA9306 같은 레벨 변환기를 넣어 MCU 쪽을 3.3 V로 둔다.
- 케이스: 화면 아래에 CardKB를 고정하는 3D 프린트 케이스 (H2).

## 5. 빌드 대상

- Cortex-M55 → `thumbv8m.main-none-eabihf`. CI가 매 커밋마다 이 대상으로도 빌드한다 (M8-9).
- STM32N6에는 칩 안 플래시가 없다: 부트 ROM이 외부 XSPI 플래시의 서명된 첫 단계 로더를 검사한 뒤 내부 RAM에서 실행한다 (M10 보안 저장·M12 출시 준비에서 서명 부팅 설계).
- Rust: `stm32n6` 레지스터 정의(PAC)는 있으나 embassy 지원은 확인되지 않았다. 화면(LTDC)·카메라(CSI/DCMIPP)·SDMMC·I2C·XSPI·클록 드라이버는 H2에서 직접 작성한다.
