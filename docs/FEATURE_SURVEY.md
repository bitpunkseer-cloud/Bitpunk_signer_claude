# 레퍼런스 프로젝트 기능 전수조사 (Feature Survey)

- 조사일: 2026-11-20 (각 저장소 기본 브랜치 최신 커밋, shallow clone)
- 조사 방법: 메뉴 정의·View/Screen 클래스·설정 정의·프로세스 핸들러·i18n 키·체인지로그를 직접 읽고,
  주요 기능 키워드를 전 저장소에서 교차 검색(테스트·벤더 코드 제외).
- 범례: **●** 지원 · **◐** 부분/조건부/특정 모델 한정 · **—** 미지원/확인 안 됨
- 약어: **SS**=SeedSigner, **KX**=Krux, **SP**=Specter DIY, **JD**=Jade, **CC**=Coldcard(Mk4/Q),
  **KS**=Keystone 3 Pro, **OK**=OneKey Pro, **PP**=Passport Prime(KeyOS)
- **채택 제안** 열은 Bitpunk Signer 제약(에어갭·무선/NFC/USB 없음·카메라·SD·QWERTY)에 맞춰 고른 것입니다.
  **아직 확정이 아니며 승인이 필요합니다.**
