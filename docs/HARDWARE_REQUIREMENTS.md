# Bitpunk Signer — 하드웨어 및 운영 요구사항

> 최종 목표: QWERTY 물리 키보드를 가진 휴대용 기기(아래 폼팩터 참조)에
> DIY 서명 펌웨어/소프트웨어를 이식한다.

## 1. 폼팩터
- 가로형 디스플레이 + 하단 풀 QWERTY 물리 키보드(백라이트 키).
- 참고 이미지 형태: 상단 4~7" 가로형 LCD, 하단 숫자열 포함 QWERTY, Fn/Ctrl/Alt/Shift 보조키.
- 세로형 변형(정사각 디스플레이 + 하단 BlackBerry형 키보드)도 후보.
- 입력은 **키보드 우선 UX**(방향키/Tab/Enter/Esc 내비게이션, 단축키). 터치는 선택 사항.

## 2. 절대 요구사항 (MUST)
| ID | 요구사항 |
|---|---|
| HW-1 | **100% 에어갭**: Wi-Fi·Bluetooth·셀룰러·LoRa 등 **무선 통신 모듈이 물리적으로 존재하지 않을 것**. (SoC 다이에 무선이 내장된 칩도 배제: 예 ESP32 계열, Pi Zero W/2W) |
| HW-2 | **NFC 없음** |
| HW-3 | **USB 데이터 연결 없음**. (USB 포트가 있다면 충전 전용, 데이터 라인 물리 차단) |
| HW-4 | **카메라 탑재**: QR 스캔으로 PSBT 서명, 시드/개인키 가져오기, 디스크립터 등록 등 수행 |
| HW-5 | **microSD 슬롯**: 최초 펌웨어 설치와 업데이트는 **SD 카드로만** 수행 |
| HW-6 | 데이터 출력 경로는 **화면 QR 표시**와 **SD 카드** 두 가지뿐 |

## 3. 개발/검증 프로세스 요구사항
- 매 개발 빌드마다 변경사항을 GitHub에 커밋·푸시.
- 빌드 결과물을 **실제 하드웨어 화면과 동일하게 생긴 웹 시뮬레이터**로 제공하고, 링크로 열어 검증·테스트 가능해야 함
  (모바일 앱 내 브라우저에서도 동작).
- **구현 전에 항상 구현 방향을 먼저 제시 → 승인 후 구현.**

## 4. 소프트웨어 원칙
- 언어: **Rust**.
- `embit`, `libwally-core` 등 기존 비트코인 라이브러리에 의존하지 않는 **독자 코드/라이브러리**.
- 표준 사양(BIP/BCR)과 공식 테스트 벡터로 검증.
